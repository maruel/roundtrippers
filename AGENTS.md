# Working in roundtrippers

Install Go and uv. Run Python commands with `uv run --locked`.
Use `make help` to discover targets. Run `make fix`, `make verify`,
and `make test` before committing. Install versioned hooks with `make git-hooks`.
`make test` runs tests with coverage and benchmark smoke tests.
